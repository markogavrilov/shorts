# Живой нарезчик Twitch

Пишет стрим и читает чат **во время эфира**. Когда чат взрывается, вырезает 30 секунд вокруг
момента и делает из них вертикальный шортс: монтаж, субтитры и уникализация. Готовый клип
появляется через 30–60 секунд после момента: в папке `clips/unique/<дата>/` и в Telegram.

```
Twitch-стрим ──streamlink──► буфер последних 4 минут (куски по 2 с)
Twitch-чат  ──► счётчик сообщений ──► всплеск ×3 от обычного? ──► МОМЕНТ
МОМЕНТ ──► вырезка (22 с до + 8 с после) ──► субтитры (Whisper)
       ──► монтаж 9:16 + уникализация ──► clips/unique/…mp4 ──► Telegram
```

## Установка (на каждом Mac, ~10 минут)

1. Скачайте папку проекта (Code → Download ZIP на GitHub) и распакуйте.
2. Откройте **Терминал**, перетащите в него файл `setup_mac.sh`, допишите спереди `bash ` и нажмите Enter.
   Скрипт ставит Homebrew, ffmpeg, Python и модель распознавания речи.
3. Откройте `config.toml` и впишите каналы: `channels = ["ник1", "ник2"]`.
4. Запуск: двойной клик по `start.command`. Если macOS не даёт открыть файл, щёлкните по нему
   правой кнопкой → «Открыть».

### Как распределить 3 компьютера

| Mac | Каналов | Сборок одновременно (`render_workers`) | Модель речи |
|---|---|---|---|
| M5 | 4 | 2 | auto (whisper-large-v3-turbo на GPU) |
| M3 | 3 | 2 | auto |
| 2015 (Intel) | 1–2 | 1 | `whisper_model = "base"` (иначе медленно) |

У каждого компьютера свой `config.toml` и **разные** стримеры. Один стример не должен быть
на двух компьютерах сразу.

Если на Mac 2015 года не ставится Homebrew (слишком старая macOS), скачайте `ffmpeg` и `ffprobe`
с evermeet.cx, положите их в `/usr/local/bin`, а Python поставьте с python.org.

## Проверка перед стримами (обязательно)

```bash
# 1. Монтаж на любом видео с компьютера (момент на 40-й секунде):
./start.command --test-file ~/Downloads/любое_видео.mp4 --moment 40

# 2. Чат живого канала: сколько сообщений и где были бы моменты (Ctrl+C — стоп):
./start.command --chat-test ник_стримера

# 3. Telegram: создайте бота у @BotFather, впишите bot_token в config.toml,
#    напишите боту /start, затем:
./start.command --telegram-setup     # покажет chat_id — впишите его и enabled = true
```

## Настройка под стримера

- **Слишком много клипов** → поднимите `spike_ratio` (3.0 → 4.0) или `min_messages`.
- **Мало клипов** (небольшой стрим) → `spike_ratio = 2.5`, `min_messages = 6`.
- **Момент обрезан в начале** → увеличьте `reaction_delay_seconds` (6 → 9).
- **Есть вебка** → `layout = "facecam"` и `facecam = [x, y, ширина, высота]` в долях кадра.
  Например, вебка в правом нижнем углу, четверть экрана: `[0.75, 0.70, 0.25, 0.30]`.

## Что делает монтаж

- вертикальный кадр: игра крупно, сверху и снизу размытый фон;
- в первые 0,35 с резкий отъезд камеры (цепляет глаз), дальше медленный наезд;
- на моменте удар-зум, тряска, белая вспышка и звук «бум»;
- в начале «вжух» и хук-заголовок крупными буквами;
- субтитры по 1–3 слова, текущее слово подсвечено и увеличено;
- полоса прогресса внизу, громкость выровнена до −14 LUFS (стандарт площадок).

## Что делает уникализация (у каждого клипа свои случайные значения)

- зум 3–8 % и сдвиг кадра; скорость 1,02–1,06× (голос не меняется);
- контраст, насыщенность, яркость, гамма, оттенок ±4°; плёночное зерно, виньетка;
- эквалайзер звука, цвета субтитров, хука и полосы, сам текст хука;
- битрейт кодирования; метаданные стираются, дата создания новая.

`variants = 3` в `[unique]` даёт 3 разные версии одного момента для разных аккаунтов.
Сырые 16:9-куски тоже сохраняются в `clips/raw/` на случай ручного монтажа.

Нарезайте только стримеров, которые разрешают клипы.
